Exactly one word: the single word grandma would text about AI.
`main.py` (Python 3.13, stdlib only) scores eight candidate words against the
judge's five criteria — grandma would text it about AI, real grandmother's
texting voice, funny in one word, tied to AI/robots/machines, fresh rather
than obvious — and writes the winner to `/output/entry.txt`.

The winning word:

> contraption

The word grandmas actually use for any new machine they do not trust: warm,
baffled, and it IS a machine word. Wry rather than loud, and nobody else's
obvious pick — the obvious pick, "robot", scored last.
